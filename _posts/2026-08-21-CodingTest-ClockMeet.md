## 📋문제

[프로그래머스 PCCP 기출문제 3번 아날로그 시계](https://school.programmers.co.kr/learn/courses/30/lessons/250135)

문제는 간단합니다
초침이 시침/분침과 겹칠 때마다 알람이 울리는 데, 특정 시간동안 알람이 울린 횟수를 구하는 문제입니다

- 제한사항
	- 알람이 울리는 횟수를 센 시간을 나타내는 정수 `h1`, `m1`, `s1`, `h2`, `m2`, `s2`
	- 0 ≤ `h1`, `h2` ≤ 23
	- 0 ≤ `m1`, `m2` ≤ 59
	- 0 ≤ `s1`, `s2` ≤ 59
	- `h1시 m1분 s1초`부터 `h2시 m2분 s2초` 까지 알람이 울리는 횟수를 센다는 의미입니다
		- `h1시 m1분 s1초` < `h2시 m2분 s2초`
		- 시간이 23시 59분 59초를 초과해서 0시 0분 0초로 돌아가는 경우는 주어지지 않습니다

## 📝풀이

### 1단계
- 시계를 *육상트랙*, 시계바늘 3개는 같은 트랙을 달리는 *속도만 다르고, 각자 일정한 속도로 뛰는 러너*라고 가정합니다.

	- 시침 = 느림보 (12시간에 한 바퀴)
	- 분침 = 중간 (1시간에 한 바퀴) 
	- 초침 = 엄청 빠름 (1분에 한 바퀴)

>**바늘이 겹친다**는 건 **빠른 러너가 느린 러너를 따라잡아 나란히 서는 순간**입니다
{: .prompt-tip}



### 2단계
- 일반적인 트랙이 100m마다 표시를 해놓은 것처럼 이 러너들이 뛰는 트랙에 *눈금 43200개* 그려줍니다. 
	- 43200인 이유는, 시침이 한 바퀴를 도는 데 걸리는 시간이 **12시간 = 43200초**이기 때문입니다. 그러면 시침은 1초에 눈금 1칸씩 가게 됩니다.

| 러너  | 한 바퀴에 걸리는 시간 | 1초에 가는 눈금          |
| --- | ------------ | ------------------ |
| 시침  | 43200초       | 43200 / 43200 = 1칸 |
| 분침  | 3600초        | 43200 / 3600 = 12칸 |
| 초침  | 60초          | 43200 / 60 = 720칸  |



### 3단계
- 만나는 순간은 **일정한 간격**으로 반복됩니다
  - 초침이 시침을 따라잡는 상황을 봅시다
	  - 초침은 1초에 720칸, 시침은 1초에 1칸
	  - 초침이 시침보다 **1초에 719칸씩 앞서 나갑니다**
	  - 한 바퀴(43200칸)를 더 앞서면 뒤에서 따라잡아 다시 만납니다
	  - 그러니 43200 / 719 = 약 60.083초마다 한 번씩 만납니다

  - 초침과 분침도 똑같이
	  - 1초에 720 - 12 = **708칸**씩 앞서 나갑니다
	  - 43200 / 708 = 3600 / 59 = 약 61.017초마다 만납니다

	 정리하면 만나는 시각들은 이렇습니다 (자정 0시 0분 0초를 0초로 놓았을 때)
	```
	초침-시침 만남 : t = (43200 / 719) * k    k = 0, 1, 2, 3, ...
	초침-분침 만남 : t = (3600 / 59) * k      k = 0, 1, 2, 3, ... 
	```

>**등간격**이라는 게 포인트입니다. 그래서 "몇 번째부터 몇 번째까지가 구간 안에 들어나"만 체크하면 됩니다
{: .prompt-info}



### 4단계
- 구간 안에 몇 개가 들어오나 셉니다
- `t1`초부터 `t2`초까지 셀 때, 이런 부등식을 풀면 됩니다

$$t_1 \le \frac {43200 \times k} {719} \le t_2$$

- 양변에 719/43200을 곱하면

$$\frac {719 \times t_1} {43200} \le k \le \frac {719 \times t_2} {43200}$$

- k는 정수니까
	- **시작 k**  = 왼쪽 값의 *올림* (ceil)
		- `a / b`
	- **끝 k** = 오른쪽 값의 *내림* (floor)
		- `(a + b - 1) / b`
	- **개수** = 끝 - 시작 + 1


### 5단계
- 12시 정각 함정만 처리하면 끝
- 0시와 12시 정각에는 세 바늘이 동시에 겹칩니다. 이 때 위 계산대로면 "초침-시침 1번" + "초침-분침 1번" = 2번으로 세어지는데, 문제에서는 ***알람이 한 번만 울린다***고 했습니다.

- 그래서 삼중 겹침이 일어난 횟수(=t가 43200의 배수인 횟수)만큼 빼줍니다

```
답 = (초침-시침 만남) + (초침-분침 만남) - (삼중 겹침)
```


## 💻 최종 코드

```
#include <algorithm>

using namespace std;

// t = (num * k) / den 형태의 시각이 [t1, t2] 안에 들어가는 k의 개수
long long countHits(long long t1, long long t2, long long num, long long den)
{
	long long from = (num * t1 + den - 1) / den;   // 올림
	long long to = (num * t2) / den;               // 내림
	return max(0LL, to - from + 1);
}

int solution(int h1, int m1, int s1, int h2, int m2, int s2)
{
	long long t1 = h1 * 3600LL + m1 * 60 + s1;
	long long t2 = h2 * 3600LL + m2 * 60 + s2;

	long long hourHits = countHits(t1, t2, 719, 43200);   // 초침-시침
	long long minHits = countHits(t1, t2, 59, 3600);      // 초침-분침
	long long tripleHits = countHits(t1, t2, 1, 43200);   // 세 바늘 동시

	return (int)(hourHits + minHits - tripleHits);
}
```
